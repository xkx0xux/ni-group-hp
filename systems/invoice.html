＋ SYSTEM 01

請求書管理システムINVOICE

見積書から領収書まで、ひとつの流れで。転記も、計算も、番号管理も、もう手作業に戻れません。

このシステムを相談する 他のシステムを見る

＋ BEFORE / AFTER

こんな手間、ありませんか。

同じ内容を、見積書と請求書に打ち直している

→

見積を作れば、納品書も請求書も領収書も引き継がれます

インボイスの記載要件が合っているか不安

→

登録番号・税率区分・税額の記載は最初から様式に入っています

消費税の端数で、請求額が合わないことがある

→

税計算は自動。手で電卓を叩く場面がなくなります

過去の請求書がどこにあるか分からない

→

取引先・期間で一覧から探せます

＋ FEATURES

できること

FEATURE 01

見積 → 納品 → 請求 → 領収

ひとつ作れば次の書類に引き継ぎ。作り直しがゼロになります

FEATURE 02

インボイス制度対応

登録番号・税率区分・税額を要件どおりに記載した様式

FEATURE 03

金額の自動計算

小計・消費税・合計を自動。端数処理の設定も可能

FEATURE 04

入金の見張り

今月の売上・未入金・期日超過をトップ画面でひと目に

FEATURE 05

PDFで出力

そのまま印刷・メール添付できる形で書き出せます

FEATURE 06

入出金管理と連携

請求した内容を、そのまま入金の見張りに渡せます
